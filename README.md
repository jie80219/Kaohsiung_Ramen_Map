# 高雄拉麵地圖

從 Instagram 與 Threads 爬梳高雄拉麵貼文，再比對讀者提供的「哇甲鬼誒Ramen」朝聖清單，逐家用 Google 地圖查證，整理成一頁式的清單。

**線上版**：`index.html`（GitHub Pages 開啟後即為首頁）

## 資料怎麼來的

1. **Threads 搜尋**：用 11 組關鍵字（高雄拉麵、高雄 拉麵 推薦、左營拉麵、鳳山拉麵、苓雅拉麵、豚骨拉麵 高雄、雞白湯 高雄、沾麵 高雄、家系 高雄、高雄 宵夜 拉麵、高雄拉麵 排隊）逐一搜尋並向下捲動累積。單一關鍵字的搜尋結果約 10–12 則就會停止載入，所以改用多關鍵字覆蓋。共蒐集約 95 則貼文，其中 35 則帶得到店名或地址。
2. **Instagram**：`#高雄拉麵` 探索頁只回得到 4 個貼文連結，且內容幾乎都是 Reels 與圖片、店名壓在圖上，抓不到文字。IG 這邊只能當交叉比對線索，無法作為主要來源。
3. **Google 地圖查證**：每一家單獨搜尋（`hl=zh-TW`），以地圖登記的正式店名為準，抓中文地址、一週營業時間、評分與評論數。
4. **比對讀者清單**：另外收到一份「哇甲鬼誒Ramen🍜」的朝聖清單（約 85 家，含非高雄店家）。逐家丟進 Google 地圖，地址不在高雄市的直接排除，剩下的補進站上。

原始爬文筆記保存在 [`data/threads_raw.md`](data/threads_raw.md)。

## 幾條規則

- **貼文與地圖不一致時，以 Google 地圖為準。** 例：火山湯海貼文寫至真路 86 號，地圖登記 186 號 → 採 186 號。
- **查不到就標「待確認」，不臆測。**
- **湯頭標籤只在店名或地圖登記名稱裡直接寫明時才標**（例如「濃厚豚骨拉麵專賣店」「東京醬油拉麵」「雞湯專門店」）。

## 資料格式

店家資料直接寫在 `index.html` 的 `STORES` 陣列裡：

```js
{
  n:"店名",              // 以 Google 地圖登記名稱為準
  area:"行政區",
  addr:"高雄市…",
  r:4.8, c:640,          // 評分 / 評論數
  soup:"豚骨",           // 選填，只在店名明寫時才有
  note:"補充說明",        // 選填
  h:[週日,週一,…,週六]   // 每天是 [開始分鐘,結束分鐘] 的區間陣列；
                         // 跨午夜以 >1440 表示（17:00–翌02:00 → [1020,1560]）；
                         // 公休為 []；整家待確認為 null
}
```

## 網站功能

- **搜尋店名與路名**：一個輸入框同時比對店名、地址（路名／巷弄）、行政區與湯頭標籤，命中的字會標色。
  拉麵店名常混用日式漢字，搜尋前會先做異體字正規化（鶏／鷄→雞、麪→麵、沢→澤、猪→豬），
  所以打「雞」也搜得到「幸花鶏白湯」。按 Esc 或右邊的 × 清除。
- 依行政區篩選
- 「現在營業中」即時篩選（每分鐘重算，正確處理跨午夜營業）
- 依評分 / 評論數 / 行政區 / 店名排序
- 每家可展開一週營業時間，今天那列會標粗
- 地址點下去直接開 Google 地圖
- 跟隨系統深色 / 淺色模式

## 顏色的用意

| 位置 | 顏色 | 意思 |
|---|---|---|
| 卡片左邊色帶、狀態圓點 | 綠 | 此刻營業中 |
| 卡片左邊色帶、狀態圓點 | 灰 | 現在沒開 |
| 卡片左邊色帶、狀態圓點 | 琥珀 | Google 地圖上查不到營業時間 |
| 評分數字、湯頭標籤、搜尋命中字 | 朱紅 | 全頁唯一的強調色，只給會變動的數字與標籤 |
| 頁首暖簾、選中的篩選鈕、地址連結 | 靛藍 | 版面底色調 |

跨午夜營業的店（一川麵舖到凌晨 2:00、金田家到 1:00、一支炭到 00:00）也會正確算進「營業中」。
